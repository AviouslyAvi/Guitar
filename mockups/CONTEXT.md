# mockups/ — UI design explorations

Ten themed static HTML mockups exploring different visual directions for the Learn section. Each is a single self-contained `.html` file with inline CSS — no JS framework, no build.

## Files

| File | Direction |
|---|---|
| `01-wax-and-wood.html` | Warm, analog, vinyl-shop feel |
| `02-field-manual.html` | Technical / instructional manual |
| `03-velvet-lounge.html` | Dark, luxurious, lounge |
| `04-broadsheet.html` | Newspaper-inspired editorial |
| `05-gallery-wall.html` | Curated-art aesthetic |
| `06-liner-notes.html` | Album liner notes vibe |
| `07-console.html` | Studio console / hardware UI |
| `08-tape-deck.html` | Vintage tape deck |
| `09-patchbay.html` | Patch-bay / synth-routing |
| `10-almanac.html` | Almanac / reference book |
| `index.html` | Landing page that links to all 10 |
| `fonts.css` | Shared font imports |
| `README.md` | Notes on the explorations |
| `HANDOFF-mockups-6-10.md` | Resume notes for the second batch (6-10) |

## Load / skip

- Open `index.html` in a browser to flip through them quickly.
- Don't `Read` more than one or two at a time — each is ~15-22 KB.
- These are **explorations**, not the production design. The chosen direction (or hybrid) lives in `app/fretboard-tutor/`.

## Relevant skills

- `frontend-design:frontend-design` — if iterating on or extracting patterns from these.
- `dirtywave-design` — only if the chosen direction lines up with that system.
