## Load / skip

- When resuming, read the **root `HANDOFF.md` first** for the current top-level state, then open the specific numbered handoff you're working on.
- Don't bulk-load all 10+ files.
- `PEDAGOGY.md` and `LESSON-COPY-TEMPLATE.md` are reference docs — load only when writing lesson copy.

## Conventions

- Filename pattern: `NN-topic-slug.md`.
- Numbering reflects planned order, not strict dependency.
- Each handoff should end with an "Exact next step" line.
